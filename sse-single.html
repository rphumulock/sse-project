📡 SSE Single Message Demo

Basic Server-Sent Events

GET /sse/single

This endpoint demonstrates Server-Sent Events (SSE) by sending a single message and then immediately closing the connection.

💡 What is SSE? Server-Sent Events allow servers to push data to web clients over HTTP. Unlike WebSockets, SSE is unidirectional (server to client) and uses the familiar HTTP protocol.

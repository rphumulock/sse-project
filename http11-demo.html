📡 HTTP/1.1 Demo

Content-Length + Connection: close

GET /api/http11-demo

This demo demonstrates HTTP/1.1 responses using explicit Content-Length and Connection: close headers. Each response includes a calculated Content-Length header and closes the connection after sending the response.

💡 How it works: The server calculates the exact size of the response body, sets the Content-Length header, and includes Connection: close to signal that the connection will be closed after this response. This is a classic HTTP/1.1 pattern that doesn't use chunked transfer encoding.

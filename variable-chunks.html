🎲 Variable Chunks Demo

HTTP Chunked Transfer Encoding with Variable-Sized Data

GET /api/variable-chunks

This endpoint demonstrates HTTP chunked transfer encoding with exponentially growing chunk sizes in a single request/response.

💡 What You'll See:

  • 10 chunks with exponentially increasing sizes (1, 10, 100, 1000... items)
  • HTTP chunked encoding (no Content-Length header)
  • Streaming response parsed in real-time as chunks arrive
  • Variable delays between chunks to simulate processing time
  • Final summary when all chunks are received
